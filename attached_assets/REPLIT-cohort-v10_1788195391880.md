# Replit prompt — Cohort.jsx v10 (delta on v9)

One change: the mobile headline still wraps "stage who get it." onto two lines.

**Why.** At `fontWeight: 700`, that line renders about 318px wide. A 360px
viewport leaves 320px after the container's 20px padding — it fitted by two
pixels, so it held on some phones and broke on others. Two fixes make it
deterministic: a fluid font size, and a non-breaking wrapper on line two.

**DO NOT** change anything else — no other component, array, section, style
constant, or file.

---

## THE CHANGE

FIND:
```jsx
          <h1 style={{ fontFamily: "'Cormorant Garamond', serif", fontWeight: 700, fontSize: mob ? 34 : 52, color: C.text1, textTransform: "uppercase", letterSpacing: "0.01em", lineHeight: 1.05, margin: "0 0 20px" }}>
            Nine other owners at your{mob ? <br /> : " "}stage{mob ? " " : <br />}
            <span style={{ color: C.gold }}>who get it.</span>
          </h1>
```

REPLACE:
```jsx
          <h1 style={{ fontFamily: "'Cormorant Garamond', serif", fontWeight: 700, fontSize: mob ? "clamp(24px, 9.2vw, 34px)" : 52, color: C.text1, textTransform: "uppercase", letterSpacing: "0.01em", lineHeight: 1.05, margin: "0 0 20px" }}>
            Nine other owners at your{mob ? <br /> : " "}
            <span style={{ whiteSpace: mob ? "nowrap" : "normal" }}>stage{mob ? " " : <br />}<span style={{ color: C.gold }}>who get it.</span></span>
          </h1>
```

Desktop is unaffected: the size stays 52, `whiteSpace` resolves to `normal`, and
the `<br />` still falls after "stage".
