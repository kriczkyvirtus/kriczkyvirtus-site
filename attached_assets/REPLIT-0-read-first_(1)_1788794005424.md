## THE RULES

### 1. Never guess. Stop and ask.

If any of the following is true, **stop, do not improvise, and report what you found**:

- A file, route, function, or environment variable named in the prompt doesn't exist
- A file exists but its contents differ from what the prompt describes
- An ID, URL, tag, or field name isn't given explicitly in the prompt
- Two instructions appear to conflict
- Something looks wrong, broken, or unusual
- A step would require creating something the prompt didn't ask for

**Do not** infer a value from a similar file. **Do not** substitute a plausible name. **Do not** create a field, tag, or table "because it seemed needed." A stopped build is cheap; a wrong ID written into production data is not.

### 2. Copy files, don't retype them

Component files are uploaded. Copy them to their target paths byte-for-byte. Do not reformat, re-indent, prettify, lint, or "clean up" anything. Do not convert inline styles to Tailwind or CSS modules.

After writing each file, verify with `sha256sum` against the value in the prompt. **Verify before pushing to GitHub.** Silent write failures on large files have happened before — a successful-looking write is not proof the content landed.

### 3. Things that look like bugs but aren't

Do not "fix" these:

- **Inline styles everywhere.** Deliberate.
- **`display: table` / `table-cell` on pills.** The only reliable vertical centring for these.
- **`gradientUnits="userSpaceOnUse"` on every SVG gradient.** Required. Axis-aligned lines have a zero-width or zero-height bounding box, and under `objectBoundingBox` the element is not painted at all — the graphic silently disappears.
- **Per-element `stroke-width` absent from icons.** Also deliberate; element-level widths override the group and break the three-pass shading.
- **The shield has no checkmark.** Correct. Older files carry `M25 32L29.5 36.5L40 26` — do not copy it forward.
- **`iframe` for iClosed rather than `widget.js`.** widget.js races the React render and intermittently never mounts.
- **Fixed `8.5in` page widths in the report.** It's a document. A viewport hook handles small screens.

### 4. Report back, every time

Each prompt ends with a **REPORT BACK** block. Fill in every line. Where a check failed, say so plainly rather than omitting it. Where you stopped and didn't do something, list it under **Not done**.

Do not mark a step complete because the code looks right. Mark it complete when you have run the check named in the prompt and seen the result.
